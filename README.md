# رستوران نارنج

صفحهٔ اصلی فارسی و راست‌چین برای برند رستوران «نارنج»، با طراحی واکنش‌گرا و آمادهٔ میزبانی روی GitHub Pages.

## فایل‌ها

- `index.html`: ساختار و محتوای صفحه
- `styles.css`: هویت بصری، چیدمان واکنش‌گرا و حالت‌های دسترس‌پذیری
- `script.js`: رفتار منوی موبایل
- `assets/narenj-hero.webp`: تصویر بهینه‌شدهٔ بخش اصلی
- `.github/workflows/pages.yml`: گردش‌کار انتشار دستی

## پیش از انتشار

نام غذاهای منو، متن‌های معرفی، نشانی، شماره تماس و ساعت پذیرایی فعلاً نمونه یا جای‌نگهدار هستند. آن‌ها را با اطلاعات واقعی رستوران جایگزین کنید. فرم تماس و رزرو نیز هنوز به سامانهٔ دریافت پیام یا رزرو وصل نشده‌اند.

## انتشار در GitHub Pages

انتشار خودکار فعال نیست. برای انتشار:

1. در **Settings → Pages**، منبع را روی **GitHub Actions** تنظیم کنید.
2. در **Actions**، گردش‌کار **Publish Narenj to GitHub Pages** را با **Run workflow** دستی اجرا کنید.

پس از انتشار، خود سایت برای عموم قابل مشاهده خواهد بود. امکان میزبانی Pages از یک مخزن خصوصی به نوع حساب GitHub بستگی دارد. GitHub Pages فایل‌های ایستا را میزبانی می‌کند؛ برای دریافت پیام و رزرو واقعی باید فرم را به یک سرویس یا API جداگانه متصل کرد.
