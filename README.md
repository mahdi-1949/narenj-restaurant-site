# نارنج | نمونه‌کار وب‌سایت رستوران

وب‌سایت فارسی و راست‌چین با هویت بصری **Dark Cinematic / Editorial**، ساخته‌شده با HTML، CSS و JavaScript و قابل انتشار روی GitHub Pages.

## صفحات

- `index.html`: صفحه اصلی، معرفی برند و دعوت به مشاهده منو
- `menu.html`: منوی تصویری با جست‌وجو، فیلتر دسته‌بندی و پنجره جزئیات غذا
- `story.html`: روایت و هویت پیشنهادی برند
- `space.html`: گالری تصویری با نمایش تمام‌صفحه
- `contact.html`: اطلاعات مراجعه و فرم آماده‌سازی پیش‌نویس پیام
- `404.html`: صفحه اختصاصی برای نشانی‌های ناموجود

## فایل‌های اصلی

- `home.css` و `home.js`: سیستم بصری و رفتارهای مشترک صفحه اصلی و هدر
- `inner.css`: طراحی مشترک صفحات داخلی و واکنش‌گرایی
- `inner.js`: فیلتر منو، جست‌وجو، پنجره جزئیات، گالری، تنظیم اطلاعات تماس و فرم پیام
- `site-config.js`: محل مرکزی ثبت شماره تماس، ایمیل، نشانی، ساعت کاری، واتساپ، اینستاگرام و لینک نقشه
- `assets/`: فونت محلی وزیرمتن و تصاویر موجود مخزن
- `sitemap.xml` و `robots.txt`: فایل‌های پایه سئو
- `.github/workflows/pages.yml`: انتشار خودکار پس از push به شاخه `main` و امکان اجرای دستی

## تنظیم اطلاعات واقعی رستوران

پیش از استفاده تجاری، فایل `site-config.js` را باز کنید و مقدارهای واقعی را وارد کنید:

- `phone`: شماره تماس با فرمت قابل شماره‌گیری
- `contactEmail`: ایمیل دریافت پیام‌ها
- `whatsapp`: شماره واتساپ با کد کشور و بدون علامت +
- `address`: نشانی کامل
- `hours`: ساعت‌های رسمی پذیرایی
- `instagram`: نشانی صفحه رسمی اینستاگرام
- `mapUrl`: پیوند مسیریابی یا نقشه

فرم تماس در حال حاضر به سرور ارسال متصل نیست. اگر ایمیل در تنظیمات ثبت شود، فرم یک پیش‌نویس در برنامه ایمیل باز می‌کند؛ برای ارسال واقعی بدون دخالت کاربر باید سرویس فرم یا API سمت سرور متصل شود. درخواست رزرو نیز تا زمان اتصال سامانه رزرو، فقط یک درخواست تماس است و تأیید خودکار نمی‌شود.

## تصاویر و محتوای نمونه

تصاویر محیط و برخی تصاویر غذا از Unsplash و Pexels فراخوانی می‌شوند؛ تصاویر غذاهای موجود در مخزن نیز در کارت‌ها استفاده شده‌اند. برای تصاویر خارجی جایگزین محلی در نظر گرفته شده است. تصاویر خارجی و تصاویر فعلی غذا، نمایشی هستند و نباید به‌عنوان عکس واقعی رستوران یا منوی قطعی معرفی شوند.

نام غذاها، شرح مواد اولیه، قیمت‌ها، اطلاعات آلرژن، تاریخچه برند، نشانی و ساعت کاری باید با اطلاعات تأییدشده رستوران جایگزین شوند. متن‌های صفحه داستان نیز روایت پیشنهادی برای نمونه‌کار هستند.

## اجرا و انتشار

برای مشاهده محلی، پروژه را با یک وب‌سرور استاتیک اجرا کنید یا فایل `index.html` را باز کنید. پس از ادغام تغییرات در `main`، GitHub Actions فایل‌های HTML، CSS، JavaScript، XML و TXT و پوشه `assets` را در GitHub Pages منتشر می‌کند.
