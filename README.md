# رستوران نارنج

صفحهٔ اصلی فارسی و راست‌چین رستوران «نارنج»، با چیدمان واکنش‌گرا و انتشار در GitHub Pages.

## بخش‌های صفحه

- معرفی رستوران و پیشنهادهای منو
- داستان و فضای نارنج
- راهنمای بخش‌های اصلی برای بازدیدکننده
- اطلاعات مراجعه و فوتر کامل با پیوندهای داخلی

## فایل‌ها

- `index.html`: ساختار و محتوای صفحه
- `styles.css`: هویت بصری، چیدمان واکنش‌گرا و حالت‌های دسترس‌پذیری
- `script.js`: منوی موبایل و نمایش خودکار سال جاری
- `assets/narenj-hero.webp`: تصویر بخش اصلی
- `assets/narenj-interior.webp`: تصویر فضای داخلی
- `assets/fonts/vazirmatn-variable.woff2`: فونت متغیر وزیرمتن برای متن‌های فارسی و عربی
- `assets/fonts/OFL.txt`: مجوز فونت وزیرمتن
- `.github/workflows/pages.yml`: گردش‌کار دستی انتشار

## فونت

فونت **Vazirmatn 33.0.3** از مخزن رسمی [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) آمده و با مجوز SIL Open Font License 1.1 توزیع می‌شود. فایل و مجوز در همین مخزن نگهداری می‌شوند تا نمایش متن به سرویس فونت خارجی وابسته نباشد.

## محتوای نمونه

نام و توضیحات غذاها نمونهٔ چیدمان‌اند. نشانی، تلفن و ساعت پذیرایی هنوز باید با اطلاعات واقعی جایگزین شوند. وب‌سایت در [GitHub Pages](https://mahdi-1949.github.io/narenj-restaurant-site/) منتشر شده، اما رزرو و فرم تماس به سامانهٔ دریافت پیام متصل نیستند.

## انتشار به‌روزرسانی‌ها

پس از هر تغییر، در بخش **Actions** گردش‌کار **Publish Narenj to GitHub Pages** را با **Run workflow** اجرا کنید. GitHub Pages فایل‌های ایستا را میزبانی می‌کند؛ برای رزرو یا ارسال پیام واقعی باید فرم‌ها را به یک سرویس یا API جداگانه وصل کرد.
