# رستوران نارنج

صفحهٔ اصلی فارسی و راست‌چین برای نمونهٔ برند رستوران «نارنج»، آمادهٔ انتشار به‌صورت سایت ایستا در GitHub Pages.

## فایل‌ها

- `index.html`: ساختار و محتوای صفحه
- `styles.css`: هویت بصری، چیدمان واکنش‌گرا و حالت‌های دسترس‌پذیری
- `script.js`: منوی موبایل
- `assets/narenj-hero.webp`: تصویر بهینه‌شدهٔ بخش اصلی

## جای‌نگهدارهای محتوایی

نام سه غذای بخش منو، متن‌های معرفی، نشانی، شماره تماس و ساعت پذیرایی نمونه‌اند یا جای‌نگهدار هستند. قبل از انتشار عمومی باید با اطلاعات واقعی رستوران جایگزین شوند. فرم تماس و رزرو هنوز به سامانهٔ بیرونی متصل نیستند.

## انتشار در GitHub Pages

پس از آماده‌شدن متن و اطلاعات واقعی، از بخش **Settings → Pages** منبع انتشار را روی **GitHub Actions** بگذارید و گردش‌کار انتشار را اضافه کنید. GitHub Pages فقط فایل‌های ایستا را میزبانی می‌کند؛ فرم‌های ارسال پیام و سامانهٔ رزرو به سرویس یا API جداگانه نیاز دارند.
