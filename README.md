# نارنج | نمونه‌کار رستوران ایرانی

وب‌سایت فارسی و راست‌چین «نارنج»، با معماری ایستا (HTML/CSS/JavaScript) و انتشار در GitHub Pages.

## ساختار

- `index.html`: صفحه اصلی بازطراحی‌شده با رویکرد **Dark Cinematic / Editorial**
- `home.css`: سیستم طراحی مستقل و واکنش‌گرای صفحه اصلی
- `home.js`: ناوبری موبایل، نوار پیشرفت اسکرول، حرکت‌های سبک و نمایش تدریجی
- `menu.html`، `story.html`، `space.html`، `contact.html`: صفحات داخلی
- `styles.css` و `script.js`: استایل و رفتار صفحات داخلی
- `assets/`: فونت محلی وزیرمتن و تصاویر موجود
- `.github/workflows/pages.yml`: انتشار خودکار روی GitHub Pages پس از تغییر شاخه `main`؛ اجرای دستی هم امکان‌پذیر است

## تصاویر

تصاویر محیط رستوران و بعضی تصاویر غذا در صفحه اصلی از نشانی‌های مستقیم Unsplash و Pexels نمایش داده می‌شوند. تصاویر غذاهای نمونه نیز از فایل‌های موجود مخزن استفاده می‌کنند. تصاویر نمایشی هستند و **نباید به‌عنوان تصاویر واقعی رستوران نارنج معرفی شوند**.

اگر ارائه آفلاین یا استقلال از سرویس‌های تصویر لازم باشد، باید تصاویر منتخب با رعایت مجوزشان در `assets/` ذخیره و نشانی‌ها جایگزین شوند. برای تصاویر خارجی، فایل‌های محلی به‌عنوان جایگزین خطای بارگذاری در نظر گرفته شده‌اند.

## محتوای نمونه

نام و توضیح غذاها برای نمایش طراحی‌اند. نشانی، شماره تلفن، ساعت پذیرایی و امکان رزرو واقعی هنوز در این نمونه‌کار تعریف نشده‌اند. هیچ فرم نمایشی به‌عنوان رزرو واقعی معرفی نشده است.

## اجرای محلی

برای مشاهده، فایل `index.html` را در مرورگر باز کنید؛ برای آزمایش مسیرها و رفتار نزدیک به محیط انتشار، یک وب‌سرور استاتیک محلی اجرا کنید.

## دسترس‌پذیری و عملکرد

صفحه اصلی از ناوبری صفحه‌کلید، لینک عبور به محتوا، برچسب‌های دسترس‌پذیر، پشتیبانی از `prefers-reduced-motion`، بارگذاری تنبل تصاویر زیر خط تا و افکت‌های مبتنی بر `requestAnimationFrame` استفاده می‌کند.
